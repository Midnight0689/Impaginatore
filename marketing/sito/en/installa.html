Install · macOS, Windows and Linux

Install Impaginatore in one minute.

Not available yet. Impaginatore goes on sale on 23 February 2027. This page already shows how it will be installed: the commands and files will work from that day.

The simplest way is a one-line command: it downloads Impaginatore from our site, checks its integrity and installs it for your user only, without asking for an administrator password. If you prefer, there is a classic installer.

Mac and Linux

Open Terminal (on a Mac: Spotlight, then type «Terminal»), paste this line and press Enter:

curl -fsSL https://impaginatore.example/installa.sh | sh

Windows

Open PowerShell from the Start menu, paste this line and press Enter:

irm https://impaginatore.example/installa.ps1 | iex

At the end the command prints a short confirmation and tells you where to find Impaginatore: in Launchpad on a Mac, in the Start menu on Windows, among your applications on Linux.

What the command does, piece by piece

Pasting a command takes trust, so here is what each part means.

Mac and Linux

curl
The program that downloads files from the internet. It is already installed on Macs and on almost every Linux.
-f
If the site answers with an error, it stops instead of running an error page.
-s
No progress bar.
-S
But if something goes wrong, it shows the error.
-L
If the address has moved, it follows the new one.
https://impaginatore.example/installa.sh
The install script, downloaded from our site over an encrypted connection. It’s a text file: you can open it and read it.
| sh
Hands the script to the shell, which runs it with your user’s permissions, not as administrator.

Windows

irm
Short for Invoke-RestMethod: downloads the content of the address that follows.
https://impaginatore.example/installa.ps1
The Windows install script, from our site, over an encrypted connection. You can open and read this one too.
| iex
Short for Invoke-Expression: runs the downloaded script in PowerShell, with your user’s permissions.

What the script does

  1. Downloads, over an encrypted connection, the right version for your system and processor.
  2. Checks the file’s SHA-256 fingerprint and the signature of our release list. If either doesn’t match, it stops and installs nothing.
  3. Installs Impaginatore in your user folder: it doesn’t touch the system and doesn’t ask for an administrator password.
  4. Creates the icon and registers impaginatore:// links, used to open your licence key straight from the email.
  5. Tells you where to find the app.

The script collects no data, installs nothing else and contacts nothing but our site. Your photos are not involved: the script never sees them.

Rather read it first?

Save it to a file, open it, and run it only after reading it:

curl -fsSL https://impaginatore.example/installa.sh -o installa.sh
less installa.sh
sh installa.sh

Classic installer

If you’d rather not use the Terminal, download the file for your system and open it like any other app.

Mac (.dmg) Windows (.exe) Linux (AppImage and .deb)

Our installers are not signed with Apple or Microsoft certificates, so the first time your system shows a warning:

  • Mac: open the .dmg file and drag Impaginatore to Applications. The first time you open it, if macOS blocks it, go to System Settings, Privacy & Security, and press «Open Anyway».
  • Windows: on the blue Windows SmartScreen window press «More info» and then «Run anyway».
  • Linux: make the AppImage executable from the file’s properties and open it, or install the .deb package with your package manager.

Checking that the file is genuine

Every download has a SHA-256 fingerprint: a string of 64 characters that changes completely if even one bit of the file changes. Fingerprints are published next to the files, on the fingerprints page. The install command checks them by itself; with the classic installer you can do it yourself:

  • Mac, in Terminal: shasum -a 256 ~/Downloads/Impaginatore.dmg
  • Windows, in PowerShell: Get-FileHash $HOME\Downloads\Impaginatore-Setup.exe -Algorithm SHA256
  • Linux, in a terminal: sha256sum ~/Downloads/Impaginatore.AppImage

The result must be identical to the published fingerprint. If it isn’t, don’t open the file and write to us at assistenza@impaginatore.example.

Requirements

macOS (Apple Silicon and Intel), Windows 10 and 11, 64-bit Linux. Minimum memory and disk: to be set after testing on all three systems.

If something goes wrong

Write to assistenza@impaginatore.example with the message you see. If the problem is in the app or the installation, we help for free. If you’d like someone to install it with you, there is support by the hour.

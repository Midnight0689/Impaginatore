# Esempio di sequenza (album Battesimo Anita, versione approvata dal cliente)

Una riga per spread: pagina sinistra | pagina destra. **I** = pagina immersiva (la griglia arriva al bordo), **W** =
pagina bianca. Moduli: FULL, DUO, VLL, V4, G4, CV, SV, PP, COL2, BAND2, STRIP3, P (cornice nella griglia 12x8), TXT
(titolo o firma); BN = bianco e nero; z = primo piano (stringe sui volti). Le foto sono indicate col nome del file.

Serve come riferimento di stile: lo spread si compone nell'editor (`/api/templates` per le disposizioni di quelle foto,
`/api/op` `newspread` / `template` / `set`), mai scrivendo un file a mano.

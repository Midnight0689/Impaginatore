Installation

Installing Impaginatore.

There is an installer for each system. You can’t download it from here yet: for now the files go to people taking part in the private beta. When the first version is out, this page will have the links.

One file for each system

  • Mac with Apple chip and Mac with Intel processor: a .dmg file for each.
  • Windows 10 and 11, 64-bit: an .exe installer that doesn’t ask for an administrator password.
  • Linux: a .deb package for Ubuntu 24.04 and the distributions based on it.

The Linux package has been tested. The macOS and Windows ones are being tested: we haven’t yet tried them on real Mac and Windows computers, and those tests will set the minimum memory and disk requirements. On Linux you can’t make layered PSDs, because there is no Photoshop.

The warning on first launch

The files are not signed with Apple or Microsoft certificates. So the first time you open Impaginatore, macOS and Windows warn you that they can’t verify who made the program. It isn’t an error: your system is asking you to decide. The installation guide explains step by step how to open it, and how to check the file’s fingerprint first, so you know it is exactly the one we published. No step asks you to turn off your computer’s protections.
